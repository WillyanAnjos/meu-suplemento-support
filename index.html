Política de Privacidade — Meu Suplemento

Última atualização: 21 de maio de 2026

O aplicativo Meu Suplemento foi desenvolvido para ajudar usuários a organizar sua rotina de suplementação, cadastrar suplementos, definir horários, controlar doses tomadas e acompanhar o histórico de consumo.

Esta Política de Privacidade explica como o aplicativo trata informações dos usuários.

Ao utilizar o aplicativo Meu Suplemento, você concorda com os termos descritos nesta Política de Privacidade.

1. Informações que o aplicativo coleta

O Meu Suplemento pode armazenar informações inseridas pelo próprio usuário, como:

  • Nome dos suplementos cadastrados;
  • Quantidade ou dose definida pelo usuário;
  • Horários de uso dos suplementos;
  • Registro diário de suplementos tomados;
  • Histórico de consumo;
  • Preferências relacionadas à rotina de suplementação.

Essas informações são utilizadas apenas para funcionamento das principais funcionalidades do aplicativo.

2. Armazenamento dos dados

Os dados cadastrados no Meu Suplemento são armazenados localmente no dispositivo do usuário, por meio de banco de dados local.

O aplicativo não exige criação de conta, login ou cadastro pessoal para uso das funcionalidades principais.

Caso o usuário desinstale o aplicativo ou limpe os dados do app nas configurações do dispositivo, as informações armazenadas localmente poderão ser apagadas permanentemente.

3. Uso das informações

As informações inseridas no aplicativo são utilizadas para:

  • Exibir a lista de suplementos cadastrados;
  • Controlar a quantidade tomada no dia;
  • Gerar histórico de uso;
  • Organizar horários de consumo;
  • Enviar lembretes e notificações, quando configurados pelo usuário;
  • Melhorar a experiência de uso do aplicativo.

O Meu Suplemento não vende dados pessoais dos usuários.

4. Notificações

O aplicativo pode enviar notificações locais para lembrar o usuário dos horários definidos para tomar seus suplementos.

As notificações são baseadas nas informações cadastradas pelo próprio usuário dentro do aplicativo.

O usuário pode desativar as notificações a qualquer momento nas configurações do dispositivo.

5. Anúncios e serviços de terceiros

O Meu Suplemento pode exibir anúncios por meio de plataformas de terceiros, como o Google AdMob.

Esses serviços podem coletar informações técnicas do dispositivo, identificadores de publicidade, dados de uso e informações aproximadas para exibição, medição e personalização de anúncios, conforme as políticas dos respectivos provedores.

O Google Play exige que apps com anúncios sejam declarados como contendo anúncios na Play Console, incluindo anúncios exibidos por SDKs de terceiros.

Serviços de terceiros que podem ser utilizados:

  • Google AdMob;
  • Google Play Services;
  • Firebase Analytics, se implementado futuramente;
  • Firebase Crashlytics, se implementado futuramente.

O tratamento de dados por esses serviços é regido pelas políticas de privacidade dos próprios provedores.

6. Dados pessoais e sensíveis

O Meu Suplemento não solicita dados como CPF, endereço, telefone, localização precisa, contatos, fotos, câmera, microfone ou informações financeiras.

O aplicativo também não tem como finalidade diagnosticar, tratar ou substituir acompanhamento médico, nutricional ou profissional.

As informações cadastradas sobre suplementos são inseridas voluntariamente pelo usuário e utilizadas apenas para controle pessoal dentro do app.

Segundo a política de dados do usuário da Google Play, apps que lidam com dados pessoais ou sensíveis devem limitar a coleta ao necessário, tratar os dados com segurança, divulgar o uso dos dados e não vender dados pessoais ou sensíveis.

7. Compartilhamento de dados

O Meu Suplemento não compartilha diretamente os dados cadastrados localmente pelo usuário, como nome dos suplementos, doses e histórico de consumo.

No entanto, serviços de terceiros usados para anúncios, análise ou estabilidade do aplicativo podem coletar determinados dados técnicos de acordo com suas próprias políticas.

O compartilhamento pode ocorrer apenas nos seguintes casos:

  • Para funcionamento de anúncios;
  • Para análise de desempenho do aplicativo, caso ferramentas de analytics sejam utilizadas;
  • Para correção de erros e falhas, caso ferramentas de crash report sejam utilizadas;
  • Quando exigido por lei, autoridade competente ou obrigação legal.

8. Segurança dos dados

O Meu Suplemento adota medidas razoáveis para proteger as informações armazenadas localmente no dispositivo.

Como os dados principais ficam no próprio aparelho do usuário, a segurança também depende das configurações do dispositivo, como senha, bloqueio de tela e proteção contra acesso não autorizado.

Nenhum método de armazenamento eletrônico é totalmente seguro, mas buscamos utilizar práticas adequadas para reduzir riscos.

9. Permissões do aplicativo

O aplicativo pode solicitar permissões necessárias para seu funcionamento, como:

  • Permissão para envio de notificações;
  • Permissão de acesso à internet, quando necessária para exibição de anúncios.

O app não deve solicitar permissões que não sejam necessárias para suas funcionalidades principais.

A política da Google Play recomenda que permissões sensíveis sejam solicitadas apenas quando forem necessárias para recursos atuais do aplicativo e de forma compreensível para o usuário.

10. Crianças

O Meu Suplemento não é direcionado especificamente a crianças.

O aplicativo é voltado para pessoas interessadas em organizar sua rotina de suplementação, treinos, academia e hábitos fitness.

Caso o aplicativo venha a ser direcionado para crianças ou usado por esse público, poderão ser aplicadas regras adicionais de privacidade e segurança.

11. Exclusão dos dados

Como os dados principais são armazenados localmente no dispositivo, o usuário pode excluir suas informações das seguintes formas:

  • Apagando os suplementos cadastrados dentro do aplicativo;
  • Limpando os dados do app nas configurações do Android;
  • Desinstalando o aplicativo.

Após a exclusão, os dados locais poderão não ser recuperados.

12. Alterações nesta Política de Privacidade

Esta Política de Privacidade pode ser atualizada periodicamente para refletir melhorias no aplicativo, alterações legais ou mudanças em serviços de terceiros utilizados.

A data da última atualização será sempre exibida no início deste documento.

Recomendamos que o usuário revise esta Política de Privacidade regularmente.
